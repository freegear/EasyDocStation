# 카카오톡 인터페이스 연동 가능 범위

> 조사 기준일: 2026-07-23  
> 이 문서는 EasyDocStation에서 카카오톡을 이용해 메시지 전송, 메시지 수신, 파일 공유 및 콘텐츠 게시 기능을 구현할 때의 가능 범위와 제한 사항을 정리한다.

## 1. 결론

카카오톡은 이메일의 IMAP/SMTP처럼 개인 사용자의 전체 대화를 외부 서비스에서 자유롭게 읽고 쓰는 범용 API를 제공하지 않는다.

따라서 EasyDocStation 안에 카카오톡과 동일한 통합 받은편지함을 만들고 개인 채팅방의 모든 메시지와 파일을 동기화하는 방식은 공식 공개 API만으로 구현할 수 없다.

대신 다음 기능은 목적에 맞는 카카오 제품을 선택하면 구현할 수 있다.

| 요구 기능 | 가능 여부 | 적합한 방식 | 핵심 제한 |
|---|---|---|---|
| 사용자가 카카오톡 친구나 채팅방에 콘텐츠 공유 | 가능 | 카카오톡 공유 | 사용자가 카카오톡 화면에서 대상을 직접 선택하고 전송해야 함 |
| 로그인한 사용자 자신에게 메시지 전송 | 가능 | 카카오톡 메시지 API의 `나에게 보내기` | 템플릿 메시지만 가능하며 사용자의 액세스 토큰 필요 |
| 같은 서비스를 이용하는 친구에게 메시지 전송 | 조건부 가능 | 카카오톡 메시지 API의 `친구에게 보내기` | 친구와 발신자 모두 앱 연결 및 동의 필요, 권한 심사 필요, 한 번에 최대 5명 |
| 서비스가 고객에게 주문·일정 등의 알림 전송 | 가능 | 알림톡 | 비즈니스 채널, 공식 딜러사, 승인된 정보성 템플릿 필요 |
| 채널 친구에게 광고·공지 발송 | 가능 | 카카오톡 채널 메시지 또는 브랜드 메시지 | 비즈니스 및 광고성 메시지 정책, 수신 동의, 과금 적용 |
| 고객이 채널에 보낸 메시지 수신 및 자동 응답 | 조건부 가능 | 카카오톡 챗봇 또는 상담톡 | 개인 대화가 아니라 서비스의 카카오톡 채널 대화만 대상 |
| 개인 채팅방 메시지 수신·대화 이력 조회 | 불가능 | 공개 API 없음 | 사용자의 일반 채팅방이나 오픈채팅방을 외부 앱에서 읽을 수 없음 |
| 문서·압축파일 등 임의 파일을 API로 첨부 전송 | 제한적 | 모바일 OS 공유 기능 또는 파일 링크 공유 | 카카오 메시지 템플릿 API는 일반 바이너리 파일 첨부 API가 아님 |
| 이미지·링크·카드 형태의 콘텐츠 게시/공유 | 가능 | 카카오톡 공유 또는 메시지 템플릿 | 카카오톡 내부 게시판을 자유롭게 작성하는 API가 아니라 메시지 전송 방식 |
| 카카오톡 채널 포스트 자동 게시 | 공개 API 기준 어려움 | 채널 관리자센터에서 운영 | 일반 공개 Developers API에 포스트 작성 API가 제공되지 않음 |

## 2. 용어 정리

요구사항의 “파일을 계시하기”는 다음 두 의미가 가능하므로 나누어 판단한다.

- 파일을 **게시하기**: 파일 또는 문서 링크를 카카오톡 메시지나 채널 콘텐츠로 알리는 기능
- 파일을 **공유하기**: 실제 파일을 카카오톡 대화방에 첨부해 보내는 기능

공개 API로는 파일 자체를 일반 채팅 첨부파일처럼 자동 전송하는 기능보다, EasyDocStation에 저장한 파일의 안전한 다운로드 링크와 설명·대표 이미지를 메시지 템플릿으로 보내는 방식이 현실적이다.

## 3. 메시지를 보내기

### 3.1 카카오톡 공유

사용자가 EasyDocStation 화면에서 `카카오톡으로 공유` 버튼을 누르면 카카오톡이 열리고, 사용자가 친구 또는 채팅방을 직접 선택해 메시지를 보낼 수 있다.

가능한 콘텐츠 예:

- 문서 제목과 요약
- 대표 이미지
- EasyDocStation의 문서 보기 링크
- 버튼이 포함된 피드·리스트·커머스·텍스트 템플릿

특징과 제한:

- 카카오 SDK를 이용하며 REST API 방식은 지원하지 않는다.
- 사용자가 공유 대상을 직접 선택하고 최종 전송해야 한다.
- 특정 친구나 채팅방으로 서버가 몰래 또는 자동 발송할 수 없다.
- 카카오 로그인 없이도 공유 기능 자체를 구성할 수 있다.
- 웹에서는 JavaScript SDK 도메인과 메시지 링크 도메인을 앱 설정에 등록해야 한다.
- 모바일에서 단순 파일을 공유할 때는 Android Sharesheet나 iOS Share Extension 같은 OS 공유 기능을 이용해 카카오톡을 공유 대상 앱으로 선택하게 할 수 있다.

사용자 주도형 문서 공유에는 이 방식이 가장 적합하다.

공식 문서: [카카오톡 공유 이해하기](https://developers.kakao.com/docs/ko/kakaotalk-share/common)

### 3.2 카카오톡 메시지 API

카카오 로그인을 완료한 사용자의 권한으로 메시지를 전송한다.

#### 나에게 보내기

- 로그인한 사용자의 `나와의 채팅`으로 보낸다.
- 문서 저장 알림, 할 일, 회의록 링크를 자기 자신에게 전달하는 용도에 적합하다.
- 다른 사용자에게 보내는 기능으로 사용할 수 없다.
- 카카오 로그인과 `talk_message` 동의가 필요하다.

#### 친구에게 보내기

- 로그인한 사용자가 같은 EasyDocStation 서비스를 사용하는 카카오톡 친구에게 메시지를 보낼 수 있다.
- 친구 피커 또는 친구 목록 API로 얻은 친구의 UUID를 사용한다.
- 한 요청에서 최대 5명에게 전송할 수 있다.
- 발신자와 수신 친구가 모두 앱과 연결되어 있고 필요한 동의 조건을 충족해야 한다.
- 앱의 `카카오톡 친구 목록/메시지` 추가 기능 사용 권한을 신청하고 심사를 받아야 실제 사용자 대상으로 운영할 수 있다.
- 권한이 없는 개발·테스트 단계에서는 앱 멤버 범위로 제한된다.
- 일반 카카오톡 친구 전체를 가져올 수 없고, 조건을 충족한 친구만 조회된다.
- 일간·월간 쿼터가 있으므로 대량 알림이나 마케팅 발송 수단으로 사용하면 안 된다.

공식 문서:

- [카카오톡 메시지 이해하기](https://developers.kakao.com/docs/ko/kakaotalk-message/common)
- [카카오톡 메시지 REST API](https://developers.kakao.com/docs/ko/kakaotalk-message/rest-api)
- [카카오톡 소셜 이해하기](https://developers.kakao.com/docs/ko/kakaotalk-social/common)

### 3.3 서비스가 고객에게 자동으로 보내기

서버가 주문, 결제, 예약, 문서 결재 요청 등의 알림을 고객에게 자동으로 보내려면 카카오톡 메시지 API보다 카카오 비즈메시지가 적합하다.

| 목적 | 권장 제품 |
|---|---|
| 주문, 배송, 결제, 예약, 보안 알림 같은 정보성 메시지 | 알림톡 |
| 채널 친구 대상 공지 또는 광고 | 카카오톡 채널 메시지 |
| 마케팅 수신 동의 회원 대상 맞춤 광고 | 브랜드 메시지 |
| 고객이 먼저 시작하는 상담 대화 | 상담톡 |

알림톡은 일반적으로 비즈니스 채널 개설, 사업자 및 채널 심사, 공식 딜러사 계약, 템플릿 사전 승인이 필요하며 유료 서비스다. 광고성 내용을 정보성 알림톡으로 보내면 안 된다.

제품 선택 기준은 [카카오톡 공유의 메시지 발송 기능 안내](https://developers.kakao.com/docs/ko/kakaotalk-share/common#message-product)를 참고한다.

## 4. 메시지를 받기

### 4.1 불가능한 범위

공식 공개 API로 다음 기능은 구현할 수 없다.

- 사용자의 개인 카카오톡 받은 메시지 가져오기
- 개인·그룹·오픈채팅방 목록 가져오기
- 기존 대화 이력 동기화
- 상대방이 메시지를 읽었는지 임의로 조회
- 개인 채팅방에서 받은 파일 자동 수집
- 카카오톡 PC 클라이언트처럼 외부 앱에서 실시간 개인 대화 송수신

카카오톡 메시지 API는 `발송 API`이며, 상대가 보낸 일반 카카오톡 메시지를 EasyDocStation 서버에 전달해 주는 수신 API가 아니다.

비공식 클라이언트 자동화, 화면 스크래핑, 사용자 세션 탈취 방식은 계정 정지, 보안 침해, 약관 위반 및 개인정보 문제 가능성이 있으므로 사용하지 않는다.

### 4.2 가능한 범위: 카카오톡 채널 챗봇

고객이 EasyDocStation의 카카오톡 채널에 메시지를 보냈을 때 그 발화를 처리하고 자동 응답하는 기능은 챗봇으로 구현할 수 있다.

처리 흐름:

1. 사용자가 EasyDocStation 카카오톡 채널의 챗봇에 메시지를 보낸다.
2. 챗봇 관리자센터가 발화와 사용자·블록·파라미터 정보를 스킬 서버로 전달한다.
3. EasyDocStation 스킬 서버가 요청을 처리한다.
4. 서버가 텍스트, 이미지, 카드, 리스트 등의 챗봇 응답을 반환한다.

주의 사항:

- 개인 채팅 전체가 아니라 해당 채널·챗봇으로 들어온 대화만 처리한다.
- 스킬 서버는 HTTPS 공개 엔드포인트와 카카오 규격의 요청·응답 처리가 필요하다.
- 일반 스킬은 짧은 응답 제한 시간이 있으므로 오래 걸리는 AI/RAG 작업은 비동기 콜백 권한과 구조를 별도로 검토해야 한다.
- 운영 전 개발 채널 테스트와 챗봇 배포 절차가 필요하다.

공식 가이드:

- [챗봇 스킬](https://kakaobusiness.gitbook.io/main/tool/chatbot/main_notions/skill)
- [스킬 서버 만들기](https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/make_skill)
- [AI 챗봇 콜백 개발 가이드](https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/ai_chatbot_callback_guide)

### 4.3 가능한 범위: 상담톡

사람 상담원이 고객의 문의를 받고 답변해야 한다면 상담톡을 검토한다.

- 사용자가 카카오톡 채널에서 상담을 먼저 요청하는 구조다.
- 상담 시스템 또는 상담톡 공식 파트너 연동이 필요할 수 있다.
- 상담 중 수신한 메시지를 EasyDocStation의 상담 화면과 연계하는 범위는 계약한 상담톡 제공사의 API와 정책을 확인해야 한다.
- 일반 사용자의 개인 친구 대화를 가져오는 기능은 아니다.

## 5. 파일을 공유하기

### 5.1 권장 방식: 보안 링크 공유

EasyDocStation에 파일을 저장하고, 카카오톡에는 파일의 메타데이터와 다운로드 링크를 보낸다.

메시지 예:

```text
[EasyDocStation 문서 공유]
2026년 7월 프로젝트 회의록
PDF · 2.4 MB

[문서 열기]
```

구현 시 다음 보안 정책이 필요하다.

- 공개 object storage URL을 영구 노출하지 않는다.
- 로그인 후 권한을 검사하는 문서 보기 URL 또는 짧은 만료시간의 서명 URL을 사용한다.
- 메시지 링크를 받은 사람이 권한이 없으면 접근을 거부하거나 소유자의 공유 승인 절차를 거친다.
- 링크 폐기, 만료일, 다운로드 제한, 감사 로그를 제공한다.
- 카카오톡 미리보기용 제목·설명·대표 이미지는 민감정보가 노출되지 않도록 최소화한다.

이 방식은 웹과 모바일 모두에서 동작하며, 파일 크기와 종류를 카카오 메시지 템플릿의 첨부 규격에 종속시키지 않는 장점이 있다.

### 5.2 이미지 공유

카카오톡 공유 API는 이미지를 카카오 서버에 업로드하거나 이미지 URL을 스크랩해 메시지 템플릿에 사용할 수 있다. 이는 메시지 카드에 표시할 이미지용이며, 범용 파일 저장·첨부 API는 아니다.

공식 문서: [카카오톡 공유 제공 API](https://developers.kakao.com/docs/ko/kakaotalk-share/common#provided-api)

### 5.3 실제 파일 첨부

- 모바일 네이티브 앱에서는 OS 공유 기능으로 파일을 카카오톡에 넘기고, 사용자가 대상과 전송을 확정하게 할 수 있다.
- 웹 브라우저에서는 특정 로컬 파일을 카카오톡 채팅방에 직접 첨부하는 일관된 공개 API가 없다.
- 서버에서 카카오톡 개인 채팅방으로 PDF, HWP, ZIP 등의 바이너리 파일을 자동 첨부하는 공개 카카오 메시지 API는 제공되지 않는다.
- 따라서 EasyDocStation 웹 서비스의 기본 구현은 `파일 링크 공유`, 모바일 앱 확장 시에는 `OS 파일 공유`를 권장한다.

## 6. 파일 또는 메시지를 게시하기

“게시”의 대상에 따라 구현 방법이 달라진다.

### 6.1 카카오톡 대화방에 게시

독립적인 게시물 API가 아니라 메시지 전송으로 처리해야 한다.

- 사용자가 대화방을 선택해 게시: 카카오톡 공유
- 자기 대화방에 저장: 나에게 보내기
- 같은 앱을 이용하는 친구에게 전달: 친구에게 보내기
- 파일 게시: 파일 다운로드 링크가 포함된 메시지

### 6.2 카카오톡 채널에 공지

채널 친구에게 공지를 발송하는 목적이라면 카카오톡 채널 메시지를 사용한다. 고객 그룹은 채널 고객 관리 API로 관리할 수 있지만, 이 API의 `고객파일`은 실제 문서 파일을 올리는 기능이 아니다. 발송 대상을 분류하기 위한 고객 데이터 집합이다.

공식 문서:

- [카카오톡 채널 이해하기](https://developers.kakao.com/docs/ko/kakaotalk-channel/common)
- [카카오톡 채널 REST API](https://developers.kakao.com/docs/ko/kakaotalk-channel/rest-api)

채널 홈의 포스트를 EasyDocStation 서버가 자동 작성하는 일반 공개 API는 확인되지 않는다. 포스트 자체는 채널 관리자 도구에서 운영하고, 자동화가 필요하면 카카오비즈니스 또는 제휴 담당자를 통해 별도 제공 여부를 확인해야 한다.

### 6.3 EasyDocStation 내부 게시 후 카카오톡으로 알림

가장 안정적인 구조는 원본 게시물과 파일을 EasyDocStation에서 관리하고 카카오톡은 알림 및 진입 경로로 사용하는 것이다.

```text
EasyDocStation에서 문서/게시물 생성
        ↓
접근 권한과 공유 링크 생성
        ↓
용도에 따라 카카오톡 공유 / 메시지 API / 알림톡 선택
        ↓
사용자가 링크로 EasyDocStation 문서 화면에 진입
        ↓
EasyDocStation에서 열람·다운로드·댓글·권한·감사 로그 관리
```

## 7. EasyDocStation 권장 기능 구성

### 7.1 1차 구현

가장 적은 심사와 운영 부담으로 시작할 수 있는 범위다.

- 문서 상세 화면에 `카카오톡으로 공유` 버튼 추가
- 카카오톡 공유 JavaScript SDK 적용
- 제목, 짧은 설명, 대표 이미지, `문서 열기` 버튼이 포함된 템플릿 제공
- 파일 자체 대신 권한이 적용된 EasyDocStation 링크 공유
- 모바일 앱이 있다면 OS 파일 공유 기능 추가
- 공유 링크 만료, 취소, 접근 로그 구현

### 7.2 2차 구현

사용자 개인 생산성 기능을 추가한다.

- 카카오 로그인 연동
- `나에게 보내기` 기능
- 회의록, 문서, 할 일, 일정 링크를 `나와의 채팅`으로 전송
- 토큰 암호화 저장, 갱신, 연결 해제 처리

### 7.3 3차 구현

사용자 간 상호작용이 핵심 요구일 때만 진행한다.

- 친구 피커 또는 친구 목록 연동
- `친구에게 보내기` 기능
- 친구 목록·메시지 사용 권한 심사
- 조건을 충족하지 않는 친구가 목록에 나타나지 않는 경우의 UI 안내
- 쿼터 초과, 동의 철회, 토큰 만료 처리

### 7.4 4차 구현

기업 고객 알림 또는 상담이 필요할 때 별도 프로젝트로 진행한다.

- 카카오톡 비즈니스 채널 개설 및 앱 연결
- 정보성 자동 알림은 알림톡
- 고객 문의 수신과 자동 응답은 챗봇
- 상담원 연결은 상담톡
- 광고·공지 발송은 채널 메시지 또는 브랜드 메시지
- 비즈니스 인증, 템플릿 심사, 공식 파트너 계약, 비용 정책 확인

## 8. 권장 화면

문서 상세 화면의 `공유` 메뉴에는 다음 항목을 제공한다.

- 카카오톡으로 공유
- 내 카카오톡으로 보내기
- 링크 복사
- 파일 다운로드
- 공유 링크 관리

`친구에게 보내기` 권한을 취득한 뒤에는 다음 항목을 추가한다.

- 카카오톡 친구에게 보내기
- 최근 공유 결과

채널 상담 기능은 개인 문서 공유 화면과 섞지 않고 별도 `카카오톡 문의` 또는 `상담` 메뉴로 분리한다.

## 9. 데이터 및 보안 원칙

- 카카오 액세스 토큰과 갱신 토큰은 서버에서 암호화해 저장하고 브라우저 로그나 URL에 노출하지 않는다.
- 사용자별·tenant별 연결 계정과 공유 데이터를 분리한다.
- 친구 정보는 카카오가 허용한 목적 범위에서만 사용하고 임의 분석, 조합, 재판매 또는 불필요한 장기 저장을 하지 않는다.
- 카카오 연결 해제와 동의 철회 시 토큰과 관련 데이터를 정리한다.
- 문서 공유 링크는 최소 권한, 만료, 폐기 및 재발급 정책을 적용한다.
- 민감한 문서의 제목이나 썸네일을 카카오톡 알림에 그대로 노출하지 않는 옵션을 제공한다.
- 메시지 내용, 수신자, 발송 시각, 성공·실패 상태를 감사 로그로 남기되 개인정보 보존 기간을 정한다.
- 마케팅 메시지는 광고성 정보 표시, 야간 발송, 수신 동의 및 철회 관련 법령과 카카오 정책을 함께 준수한다.

## 10. 사전 준비 사항

1. 카카오디벨로퍼스에서 앱을 생성한다.
2. Web 플랫폼 도메인과 Redirect URI를 등록한다.
3. 카카오 로그인을 활성화한다.
4. 필요한 동의항목만 설정한다.
   - 카카오톡 메시지 전송
   - 친구 기능 사용 시 카카오 서비스 내 친구목록
   - 채널 관계 기능 사용 시 카카오톡 채널 추가 상태 및 내역
5. 메시지 기본 템플릿 또는 사용자 정의 템플릿을 만든다.
6. 개발자 앱 멤버로 공유 및 메시지 전송을 시험한다.
7. 친구 메시지 기능이 필요하면 실제 동작 화면을 준비해 추가 기능 사용 권한을 신청한다.
8. 비즈메시지가 필요하면 비즈니스 채널, 공식 파트너, 템플릿 심사와 비용을 확인한다.
9. 운영 전 쿼터와 최신 정책을 다시 확인한다.

## 11. 최종 권장안

EasyDocStation의 카카오톡 연동은 다음 원칙으로 설계한다.

- 카카오톡을 문서 저장소나 통합 메신저 서버로 사용하지 않는다.
- 문서와 파일의 원본, 접근 권한, 댓글, 이력은 EasyDocStation에서 관리한다.
- 일반 사용자의 공유는 `카카오톡 공유`를 기본으로 한다.
- 자기 알림은 `나에게 보내기`를 선택 기능으로 제공한다.
- 서버 자동 알림은 알림톡, 고객 수신 대화는 챗봇 또는 상담톡으로 분리한다.
- 파일은 기본적으로 안전한 문서 링크로 공유하고, 모바일에서만 OS 파일 공유를 보조 기능으로 제공한다.
- 개인 카카오톡 받은편지함과 대화 이력 동기화 기능은 구현 대상에서 제외한다.

이 구성이라면 카카오의 공개 정책 범위 안에서 문서 공유, 자기 알림, 고객 알림, 채널 상담을 단계적으로 제공할 수 있다.
